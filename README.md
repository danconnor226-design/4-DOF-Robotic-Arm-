# 4-DOF-Robotic-Arm-

Core Components:

- Arduino UNO R3.
- NiMH/Alkaline AA (4x)
- SG90 Micro Servo (4x)
- 400 pin breadboard.
- 4S AA Battery Holder.

Chassis Material: Popsicle sticks, Illustration board.

Coding Language: C++, written in Arduino IDE.
